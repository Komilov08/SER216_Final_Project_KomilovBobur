# SER216 Final Project — Digital Parking Permit System

**Student:** Bobur Komilov
**Course:** SER216 — Software Engineering
**Project:** Digital Parking Permit System

## Project Overview

A university wants a digital parking permit system. Students and staff can register vehicles,
request parking permits, check available parking zones, and report parking issues. Security
staff can verify permits and update violation records.

This repository contains the full deliverables for the practical final exam:

1. Functional and non-functional requirements
2. A workflow diagram of the permit lifecycle
3. A test case table covering system, acceptance, and regression testing
4. Defect analysis for a real-world scenario
5. GitHub evidence (branch, commits, pull request, merge)
